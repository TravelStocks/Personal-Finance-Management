# Personal Finance Management

一个长期个人财务管理网页，用来手动维护收入、支出、账户、资产分配、投资、应急金、提醒、目标和财务报表。

## 功能

- 年度与月份类型预算：按9个普通月、3个出差月、90个领补贴自然日及预算汇率6.70测算。工资156,000元与出差净结余30,150元，全年可分配186,150元；全部安排161,100元，含投资与应急储备45,000元，另余25,050元。
- 完整分配表和周转参考：普通月全部安排13,500元，工资13,000元，缺口500元；出差月安排13,200元、平均余量9,850元。未擅自压缩其他额度。期初应急2,000元加全年新增12,000元，全年后参考14,000元，6个月应急目标保守下限39,300元。出差具体月份和补贴到账时间尚未确定，不生成虚构的逐月到账计划。
- 分配表显示房租、家用、投资基金、应急&学习金、旅游基金、伴侣基金、小额支付、日常使用八类。应急&学习金合计2,000元，其中应急1,000、学习1,000；计算上仍分别记为储备和消费预留。编辑时可分别修改两部分。小额支付普通月1,000元、出差月0元；日常使用普通月1,000元，出差月1,700元。旧500元应急标准一次性迁移到1,000元，升级后可自由修改，历史复盘预算快照不改写。首页、预算管理、现金流核对表与图表共用同一方案。
- 年度积累与税后奖金情景：固定储蓄投资目标为45,000元 + B，包含预算余量的预计积累仍为70,050元 + B；多划拨应急改变资金构成，不增加总积累。奖金默认待确认；10,000/20,000/30,000元奖金的预计积累为80,050/90,050/100,050元，占含该奖金的可分配资金约40.8%/43.7%/46.3%。本金、应急新增和余量分别列示，不计已有余额或投资涨跌。
- 年度模型独立随本地保存、完整版本、备份与加密云同步存储；旧备份自动补上年度参考方案，原有收入、支出、账户、投资持仓和历史月份不会被预算覆盖。计算参数与分配金额均可修改，普通/出差月份切换与总览和预算图表联动。
- 预算与账本分开保存：修改年度方案不覆盖历史收支、资产或账户余额；旧月度方案字段仍保留以兼容备份。公司借款沿用账本中的原记录，调拨还款后需按实际剩余欠款更新，未将“基本能够还完”自动视为已结清。
- 总览中的可分配资金、生活消费、投资应急与现金余量引用同一份年度方案和所选月份类型；父母家用、旅游和伴侣基金不标为个人投资储蓄，预算不标为已发生的实际分配。
- 总览 Dashboard：总资产、总储蓄、总负债、应急金、本月收入、本月支出、资产分配、6 个月预测。
- 收入管理：工资规划统一为13,000元，年度预算、现金流参数、6个月预测、现金流日历和瀑布图共用规划值。旧数据一次性将2026年10月起的工资记录更新到13,000元，更早实际收入及已保存复盘/月度存档不改写。之后修改规划工资联动当月及后续月份，单月实际到账仍可单独核实。
- 支出管理：按月份维护细项、所属大类、实际净支出、具体用途及必要/固定标记，可补充日常和学习常用细项。旧记录不自动改分类、不修改金额。新增月份复制分类与参考额度，但清空实际支出和上月用途。学习用途在支出、应急&学习金及月度报告中汇总；未归类金额单独提示。咔皮单笔>10元报告不被当作全部消费，小额汇总及未覆盖金额须核对，退款可填负数。
- 现金流预测：未来 6 个月收入、支出、分配和预计余额。
- 账户管理：银行卡、支付宝、微信、证券账户、余额宝、现金等账户可新增、删除和编辑。
- 投资管理：A 股、美股、港股市值、成本、盈亏和汇率换算。
- 资产负债表、应急金、账单提醒、目标管理、财务报表、健康评分和未来数据能力模块。
- 大花费项目：把旅行、搬家、手机分期、应急金和投资待投金拆开，显示缺口、每月补齐压力和未分配现金。
- 月度分析报告：自动生成净资产、现金流安全、投资比例、大花费项目、家庭责任、应急金与负债的复盘建议。
- 月度存档：手动保存每月收入、支出、账户余额、总资产和净资产，用于环比追踪。
- 周期复盘：按周、月、季度录入收入、九类发生额及四项期末资产负债，保存后与最近同类周期比较并生成报告。可带入账户管理逐项核对期末余额和变动说明，现金合计由计入账户汇总，证券账户或他人资金需排除避免重复。核对确认后保存独立账户快照，逐账户比较上期；仅截至当天且勾选同步时回写现有账户余额，历史修订、导入和汇总不自动覆盖当前账户。月报保留预算快照，汇总取最后一期账户余额而非累加。复盘记录随本地数据、完整备份和加密云同步保存。
- 云同步：用 GitHub 私密 Gist 保存加密后的完整数据包；点击保存完整版本/月报后可立即写入云端，另一台电脑可恢复同一份数据。
- 周期复盘关键事项：三行折叠核对项带入大花费项目、账单与订阅提醒、资产负债明细，核对后随本期保存独立快照。报告开头仅展示收支、项目、账单、资产负债四项摘要及最多三条下期动作；可展开详细变化，下载报告包含完整说明。按复盘截止日检查未来30天项目缺口、未来7天到期提醒，过期事项仅提示核实，不推断欠款或已支付。来源模块变化后须刷新重新核对；旧记录缺少快照不当作零，项目预留与提醒不重复计为资产或消费，季度汇总只取末期期末快照。

## 本地运行

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```

## 隐私说明

页面默认使用脱敏账户名称，不包含原始截图、完整账号、微信号或账单文件。默认自动保存只保存在当前浏览器本地；跨电脑使用时请在“云同步”模块填写 GitHub Token、Gist ID 和同步密码，点击“保存完整版本”或“保存到云端”会先在浏览器中加密再上传。需要打开网页时自动恢复云端数据，可以在本机勾选“打开时自动恢复”，同步密码会只保存在当前浏览器。

## 周期复盘 Skill

可复用 skill 源码位于 `skills/personal-finance-review`，安装到本机 Codex skills 目录后，用“使用 $personal-finance-review 开始本周财务复盘”调用。第一次建立基准，后续提交实际数据后才有前后对比，不从默认账本推测当前余额。

```bash
node scripts/finance-review.cjs template --type week --end 2026-11-01
node scripts/finance-review.cjs save --input .private-finance/intake.json
node scripts/finance-review.cjs aggregate --type month --end 2026-11-30 --mode normal
node --test tests/annual-budget.test.cjs tests/monthly-cash-plan.test.cjs tests/finance-review.test.cjs
```

模板、历史、修订前备份、Markdown 报告和网页导入文件默认在 Git 忽略的 `.private-finance/`。汇总只生成待核对草稿；同周期修订需明确 `--replace`。在网页“周期复盘”导入 `website-import.json` 后保存完整版本到已配置云端；本地 skill 历史不会自动读取网页存储，换电脑时先导出网页的最新复盘记录并合并。严禁把实际财务记录作为公开站点内容提交。
