# Personal Finance Management

一个长期个人财务管理网页，用来手动维护收入、支出、账户、资产分配、投资、应急金、提醒、目标和财务报表。

## 功能

- 年度与月份类型预算：按9个普通月、3个出差月、90个领补贴自然日及预算汇率6.70测算。工资156,000元与出差净结余30,150元，全年可分配186,150元；全部安排155,100元，含投资与应急储备39,000元，另余31,050元。
- 完整分配表和周转参考：普通月全部安排13,000元，与工资持平；出差月安排12,700元、含平均补贴净结余的余量10,350元。期初应急参考2,000元加全年新增6,000元，全年后参考8,000元。必要支出基数统一为4,750元，6个月应急目标28,500元；该基数不再另加房租、家用或餐费。出差补贴到账未确定，不视为可用现金。
- 分配表显示房租、家用、投资基金、应急&学习金、旅游基金、伴侣基金、小额支付、日常使用八类。应急&学习金合计1,500元，其中应急500、学习1,000；计算上仍分别记为储备和消费预留。小额支付普通月1,000元、出差月0元；日常使用普通月1,000元，出差月1,700元。旧方案一次性迁移应急月度投入到500元、必要基数到4,750元，之后的自定义修改会保留；不改历史实际收入、支出、账户余额及复盘快照。
- 年度积累与税后奖金情景：固定储蓄投资目标为39,000元 + B，包含预算余量的预计积累仍为70,050元 + B；调整应急划拨仅改变资金构成，不增加总积累。奖金默认待确认；10,000/20,000/30,000元奖金的预计积累为80,050/90,050/100,050元，占含该奖金的可分配资金约40.8%/43.7%/46.3%。本金、应急新增和余量分别列示，不计已有余额或投资涨跌。
- 年度模型独立随本地保存、完整版本、备份与加密云同步存储；旧备份自动补上年度参考方案，原有收入、支出、账户、投资持仓和历史月份不会被预算覆盖。计算参数与分配金额均可修改，普通/出差月份切换与总览和预算图表联动。
- 首页与预算管理的分配金额直接可编辑，普通月和出差月分别维护；应急、学习分开输入、合并展示，全年预算与合计只读并自动重算。支持零值及两位小数，非法金额不会重置已有预算。“保存分配预算”复用全局保存和云同步，修改也随现有自动保存保留，不改写历史实际收支。
- 预算与账本分开保存：修改年度方案不覆盖历史收支、资产或账户余额；旧月度方案字段仍保留以兼容备份。公司借款沿用账本中的原记录，调拨还款后需按实际剩余欠款更新，未将“基本能够还完”自动视为已结清。
- 总览中的可分配资金、生活消费、投资应急与现金余量引用同一份年度方案和所选月份类型；父母家用、旅游和伴侣基金不标为个人投资储蓄，预算不标为已发生的实际分配。
- 总览 Dashboard：总资产、总储蓄、总负债、应急金、本月收入、本月支出、资产分配、6 个月预测。
- 收入管理：工资规划统一为13,000元，年度预算、现金流参数、6个月预测、现金流日历和瀑布图共用规划值。旧数据一次性将2026年10月起的工资记录更新到13,000元，更早实际收入及已保存复盘/月度存档不改写。之后修改规划工资联动当月及后续月份，单月实际到账仍可单独核实。
- 支出管理：按月份维护细项、所属大类、实际净支出、具体用途及必要/固定标记，可补充日常和学习常用细项。旧记录不自动改分类、不修改金额。新增月份复制分类与参考额度，但清空实际支出和上月用途。学习用途在支出、应急&学习金及月度报告中汇总；未归类金额单独提示。咔皮单笔>10元报告不被当作全部消费，小额汇总及未覆盖金额须核对，退款可填负数。
- 现金流预测：当前工资和年度分配共用数据，不读旧账本预算、旧市场投入计划或旧隐藏行。额外现金流单列且不得重复预算；工资以外未确认到账的补贴不预支。从当前可自由动用余额测算六个完整月情景，非本月剩余天数的逐日到账预测。账单日历只提醒，不重复扣除预算内费用。
- 账户管理：银行卡、支付宝、微信、证券账户、余额宝、现金等账户可新增、删除和编辑。
- 投资管理：A 股、美股、港股市值、成本、盈亏和汇率换算。
- 资产负债表、应急金、账单提醒、目标管理、财务报表、健康评分和未来数据能力模块。
- 大花费项目与现金流共用可动用核对：可提取账户余额减专项账户占用、项目追加锁定。投资、应急、旅游、学习及家庭专户按用途识别；项目可显式关联资金所在账户，专户已锁定部分只扣一次，多个项目先按账户合并。未关联的已准备项目保守地另扣并提示核对，超额占用或负余额显示警告，非流动账户不当作可提取现金，未准备缺口不直接扣现有余额。过期项目待核实，不计入未来每月筹款压力。
- 月度分析报告：自动生成净资产、现金流安全、投资比例、大花费项目、家庭责任、应急金与负债的复盘建议。
- 月度存档：手动保存每月收入、支出、账户余额、总资产和净资产，用于环比追踪。
- 周期复盘：按周、月、季度录入收入、九类发生额及四项期末资产负债，保存后与最近同类周期比较并生成报告。可带入账户管理逐项核对期末余额和变动说明，现金合计由计入账户汇总，证券账户或他人资金需排除避免重复。核对确认后保存独立账户快照，逐账户比较上期；仅截至当天且勾选同步时回写现有账户余额，历史修订、导入和汇总不自动覆盖当前账户。月报保留预算快照，汇总取最后一期账户余额而非累加。复盘记录随本地数据、完整备份和加密云同步保存。
- 保存：顶部“保存当前数据”和应急模块“保存应急设置”立即保存当前账本及规划参数，不另建历史版本；修改后延迟300毫秒自动保存，页面打开期间每30秒补存，隐藏/离开页面时补存最新值。状态明确区分本机保存与云端同步，存储失败时提示导出备份；其他标签页已更新数据时暂停覆盖，提示备份后刷新。周期复盘未提交的输入仍需点击“保存并分析”形成记录。
- 云同步：用 GitHub 私密 Gist 保存加密后的完整数据包；配置完成后点击保存当前数据/应急设置/完整版本/月报可立即写入云端。开启自动云同步后仅上传有变化的数据，失败时保留本机修改并在后续周期重试；上传期间发生的新修改不标为已同步。重新打开时本机有未同步修改则保留本机版本，暂停自动覆盖和上传，待用户保存到云端或确认手动拉取；打开时拉取失败也不会自动把默认数据反向上传。
- 周期复盘关键事项：三行折叠核对项带入大花费项目、账单与订阅提醒、资产负债明细，核对后随本期保存独立快照。报告开头仅展示收支、项目、账单、资产负债四项摘要及最多三条下期动作；可展开详细变化，下载报告包含完整说明。按复盘截止日检查未来30天项目缺口、未来7天到期提醒，过期事项仅提示核实，不推断欠款或已支付。当天未保存的新复盘自动联动来源模块，只重置发生变化组的核对状态，保留已填金额与说明；历史修订和汇总快照不自动覆盖，手动刷新须确认。旧记录缺少快照不当作零，项目预留与提醒不重复计为资产或消费，季度汇总只取末期期末快照。
- 账单倒计时：按北京时间当前日期计算自然日差，页面跨日及重新获得焦点时更新；区分今天、未来、已过期和日期待补，不再使用固定演示日期。账单金额合计保留小数位，不推断是否已支付。

## 隐私说明

页面默认使用脱敏账户名称，不包含原始截图、完整账号、微信号或账单文件。默认自动保存只保存在当前浏览器本地；跨电脑使用时请在“云同步”模块填写 GitHub Token、Gist ID 和同步密码，点击“保存当前数据”“保存完整版本”或“保存到云端”会先在浏览器中加密再上传。新电脑首次连接后手动拉取同一个Gist；需要后续打开网页时自动恢复云端数据，可以在本机勾选“打开时自动恢复”，同步密码会只保存在当前浏览器。存在本机未同步修改时不会自动覆盖，先核对本机与云端版本。

## 日期收支与复盘联动

总览显示最近已保存周复盘的收入、实际消费、收支结余和期末净资产，并比较上一非重叠周；日期和天数单独标明。周快照不与月账本重复相加。月度卡片读取所选自然月账本的已录入收支，不再用年度工资规划替代；10号起的财务月仍在周期复盘中查看。

“保存、更新看板并分析”默认提交最新一期周复盘，不再限于当天。须核对现金账户、逐账户投资与汇率、项目、账单、资产负债和目标余额。所有明细按原ID更新源模块，保留账户用途、可提取属性、项目资金账户关联和预算计划。缺失、无效、过时或合计不一致的数据阻止整次提交，先完成一次本机原子写入，再更新界面。勾选不计入个人现金的账户会从总览和流动性中排除；投资与应急净划拨不记消费，已核对期末余额不再按周收支重复加减。完成整期核对后，目标余额只作计划跟踪，不另加一份个人现金。

逐账户投资明细与投资管理使用同一清单，保存原币成本、期末金额、汇率和说明；报告按ID对比同一市场的多个账户，余额变化不冒充收益。月/季汇总取最后一期投资快照，不累加余额。旧复盘缺少明细时保留原报告，更新看板前须重新带入并核对。

每次保存或修订都在 `data.reviewUpdates` 中留存完整更新前后数据（不递归包含历史本身），与当期数据同一次写入、导出和加密云同步，不受20个手动快照上限裁剪。复盘底部“整期更新历史与趋势”可查看、导出前后版本；导出版本保留完整更新历史。存储不足或跨页面冲突时提交失败，不删旧版本腾空间，不报告成功。较早/未来一期、月季报告及单独导入只存报告，不覆盖最新看板；当前模块在填写期间变化时须重新带入核对。

周复盘保存默认同步未入账消费：先扣除本周日期明细，再把差额保存为带起止日期的周汇总（不是伪造单日交易），同周期修订替换原汇总。收入必须与工资及其他到账日期明细一致；跨自然月且有未标日期消费时阻止回写，要求补日期。旧月度累计须先补日期以免重复入账；取消同步只保存报告，不撤销此前账目。月/季报告、导入记录不会再次入账。收入、支出模块展示已保存周复盘变化；支出按大类折叠，日常使用可展开细项，汇总行通过原复盘修订。未归类旧记录不擅自分类。

周复盘内可直接保存、修改工资和其他收入的日期明细，同步收入账本，并单独联动本期收入合计，不覆盖手填支出。收入输入尚未保存时阻止生成报告；核对后保存收入日期快照，报告区分工资、其他收入及到账时间。完整收支联动仍保留，历史报告不随源账本变化改写。

新月复盘默认每月10日至下月9日（10号只归新账期）；旧自然月记录保留，按各自口径比较。周复盘仍按周一至周日，季度沿用自然季度。10号账期简表按周展示已标日期的工资、其他收入、支出和结余，首尾周按账期截取，不重复计数；未登记不等于零，手填复盘金额不冒充日期明细。CLI 月模板默认同一账期，可用 `--month-start 1` 显式创建自然月模板；不能把跨账期的周总额按天摊分。

收入、支出模块可按日期保存明细。已有月度累计用“补录日期”拆分，月度总额不变；新发生的收支用“新增实际”，保存、修改、删除时同步调整所属月份的实际金额。退款填负数，支出需确认粗分类归属。未标日期的旧金额不自动分配给任何周，工资规划和股票浮盈不自动视为到账；有日期工资记录的月份不再被工资规划覆盖。

周期复盘按起止日期（包含两端）带入已登记收入与七类实际消费，投资、应急划拨仍单独填写。首次带入需确认替换已有输入；联动期间源数据变化会刷新金额并重置核对确认。保存前确认本期收支完整，已保存报告冻结日期明细快照，后续改账不改历史；可明确重新带入后修订。未分类明细阻止带入，未标日期余额提示核对。日期明细与月度实际成对保存，完整备份及加密云同步均包含明细；单独导入复盘报告不回写账本。支出事项和学习用途随日期明细进入报告。

## 周期复盘 Skill

可复用 skill 源码位于 `skills/personal-finance-review`，安装到本机 Codex skills 目录后，用“使用 $personal-finance-review 开始本周财务复盘”调用。第一次建立基准，后续提交实际数据后才有前后对比，不从默认账本推测当前余额。

```bash
node scripts/finance-review.cjs template --type week --end 2026-11-01
node scripts/finance-review.cjs save --input .private-finance/intake.json
node scripts/finance-review.cjs aggregate --type month --end 2026-11-30 --mode normal
node --test tests/annual-budget.test.cjs tests/monthly-cash-plan.test.cjs tests/finance-review.test.cjs
```

模板、历史、修订前备份、Markdown 报告和网页导入文件默认在 Git 忽略的 `.private-finance/`。汇总只生成待核对草稿；同周期修订需明确 `--replace`。在网页“周期复盘”导入 `website-import.json` 后保存完整版本到已配置云端；本地 skill 历史不会自动读取网页存储，换电脑时先导出网页的最新复盘记录并合并。严禁把实际财务记录作为公开站点内容提交。
