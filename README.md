# Personal Finance Management

一个长期个人财务管理网页，用来手动维护收入、支出、账户、资产分配、投资、应急金、提醒、目标和财务报表。

## 功能

- 月度现金计划：默认载入最新安排，到手工资13,000元、生活费3,500元、投资2,750元、旅游1,000元、应急500元，全部安排14,000元，现金缺口1,000元；保留原拨款12,500元作为对照。支持原安排、保留少量投资、加快还款三种可编辑草案，以及6个月本金与现金余量测算。
- 预算与账本分开保存：月度计划随本地备份、历史快照及加密云同步保存；修改草案不覆盖历史收支、资产或账户余额。公司借款本金沿用先前20,000元估算，调拨还款后按实际剩余欠款更新，实际还款期限待确认。
- 总览 Dashboard：总资产、总储蓄、总负债、应急金、本月收入、本月支出、资产分配、6 个月预测。
- 收入管理：按月份记录工资、炒股月结、其他收入。
- 支出管理：按月份维护预算、实际支出、必要/可取消支出、固定支出。
- 现金流预测：未来 6 个月收入、支出、分配和预计余额。
- 账户管理：银行卡、支付宝、微信、证券账户、余额宝、现金等账户可新增、删除和编辑。
- 投资管理：A 股、美股、港股市值、成本、盈亏和汇率换算。
- 资产负债表、应急金、账单提醒、目标管理、财务报表、健康评分和未来数据能力模块。
- 大花费项目：把旅行、搬家、手机分期、应急金和投资待投金拆开，显示缺口、每月补齐压力和未分配现金。
- 月度分析报告：自动生成净资产、现金流安全、投资比例、大花费项目、家庭责任、应急金与负债的复盘建议。
- 月度存档：手动保存每月收入、支出、账户余额、总资产和净资产，用于环比追踪。
- 云同步：用 GitHub 私密 Gist 保存加密后的完整数据包；点击保存完整版本/月报后可立即写入云端，另一台电脑可恢复同一份数据。

## 本地运行

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```

## 隐私说明

页面默认使用脱敏账户名称，不包含原始截图、完整账号、微信号或账单文件。默认自动保存只保存在当前浏览器本地；跨电脑使用时请在“云同步”模块填写 GitHub Token、Gist ID 和同步密码，点击“保存完整版本”或“保存到云端”会先在浏览器中加密再上传。需要打开网页时自动恢复云端数据，可以在本机勾选“打开时自动恢复”，同步密码会只保存在当前浏览器。
